# Portfolio — Doha Jaafari

## À propos du projet

Ce projet consiste à concevoir et développer mon portfolio personnel dans le cadre de mon Master 1 **Humanités numériques — Numérique : Enjeux et Technologies** à l'Université Paris 8.

Ce portfolio a pour objectif de présenter mon parcours, mes compétences, mes expériences et mes projets dans les domaines de l'UX/UI Design, du Webdesign et de l'intégration web.

## Ambitions du projet

L'objectif est de créer un portfolio qui soit à la fois professionnel, accessible et agréable à utiliser.

Je souhaite notamment :

* présenter mon parcours académique et professionnel ;
* mettre en valeur mes projets et mes expériences ;
* présenter mes compétences et les outils que j'utilise ;
* montrer ma démarche de conception et de design ;
* améliorer mes compétences en programmation web ;
* créer une expérience utilisateur simple et intuitive ;
* rendre le portfolio accessible en ligne avec GitHub Pages.

## Contenu du portfolio

Le portfolio sera organisé autour de plusieurs sections :

* **Accueil** : présentation de mon profil et de mon univers.
* **À propos** : parcours, formation et présentation personnelle.
* **Projets** : présentation de mes différents projets et réalisations.
* **Compétences** : outils, technologies et compétences en UX/UI et Webdesign.
* **Expériences** : stages et expériences professionnelles.
* **Contact** : moyens de me contacter et liens professionnels.

## Technologies envisagées

Le projet sera développé progressivement avec :

* HTML
* CSS
* JavaScript
* GitHub
* GitHub Pages

## Démarche

Le projet sera développé progressivement. Je commencerai par une première structure fonctionnelle, puis j'améliorerai progressivement le design, la navigation, le contenu et les interactions.

L'objectif est également de mettre en pratique les notions de programmation étudiées dans le cadre du Master Humanités numériques.

## Résultat attendu

À terme, le projet doit aboutir à un portfolio personnel responsive et accessible en ligne, permettant de découvrir mon profil, mon parcours et mes réalisations.
